# FAQ Accordion – Frequently Asked Questions

A modern and responsive FAQ accordion website built with HTML5, CSS3, and Vanilla JavaScript. This project is designed to be clean, beginner-friendly, and ready for GitHub Pages deployment.

## Features

- Modern hero section with search bar and brand header
- 10 interactive FAQ accordion items
- Smooth open/close transitions with accessible button controls
- Single-item accordion behavior (only one FAQ remains open at a time)
- Live search filtering for FAQ questions and answers
- Friendly no-results message when no matches are found
- Responsive layout for mobile, tablet, and desktop devices
- Contact section and polished footer
- Accessibility-friendly markup with ARIA attributes

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Instructions to Run Locally

1. Download or clone the project folder.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use a local preview extension such as Live Server.
4. To use Live Server in VS Code:
   - Install the Live Server extension.
   - Right-click `index.html` and select "Open with Live Server".

## How to Deploy Using GitHub Pages

1. Create a GitHub repository.
2. Open the terminal in the project folder.
3. Run the following commands:

```bash
git init
git add .
git commit -m "Initial FAQ Accordion project"
git branch -M main
git remote add origin https://github.com/your-username/rutvibjadav.git
git push -u origin main
```

4. In your GitHub repository, go to **Settings**.
5. Open **Pages** from the left sidebar.
6. Under **Source**, choose the **main** branch and **root** folder.
7. Save the settings.
8. GitHub will provide a live URL for your site.
